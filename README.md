# gpclean

One-time Google Photos cleanup: find duplicates and junk in a Google Takeout
export (processed in GitHub Actions, straight from Google Drive), review them
locally with a small web app and Claude (via MCP), and delete manually in
Google Photos.

**Status:** under construction. Setup instructions will land here.

This repository is public. It never contains photos, thumbnails, indexes,
logs with personal data, or credentials.
